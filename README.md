# ThinkSecure Lab – Visiting Card to Website (Frontend Project)

🔗 Live Website: https://69ef6f2bb9ba3546999c6d56--thinksecure-lab.netlify.app/

## Project Description

This project converts a ThinkSecure Lab business visiting card into a modern responsive website using React and Tailwind CSS.

The website displays company services, automation solutions, and contact details in a professional digital format.

## Services Included

The website presents the following services:

- CCTV Installation
- Motion Sensor Systems
- Gate Automation
- Water Level Control
- Curtain Motor Automation
- Solar Installation
- Step Automation Lighting
- Customized Smart Automation Solutions

## Features

- Full-screen responsive layout
- Light brown and cream color theme
- Smooth navigation between sections
- Services display cards
- Image gallery section
- About section
- Contact details section
- Clean modern UI design

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## How to Run the Project

Clone repository:

git clone https://github.com/khushichavan/thinksecure-lab-website.git

Open project folder:

cd thinksecure-lab-website/Lab

Install dependencies:

npm install

Run project:

npm run dev

Open in browser:

http://localhost:5173

## Project Objective

The objective of this project is to convert a physical visiting card into a professional website interface using modern frontend technologies.
